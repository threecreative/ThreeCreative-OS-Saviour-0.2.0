# Contributing to ThreeCreative OS Saviour

Thank you for your interest in the project.

This repository is a proprietary alpha-stage project and not an open-source community project by default. Contributions are welcomed only where explicitly approved by ThreeCreative.

## Scope

This repository is primarily intended for:

- issue reporting
- release verification and troubleshooting
- product feedback
- licensing and commercial discussion
- testing of the early prototype image

## Before contributing

Please confirm the following:

1. You have permission to share any files, logs, or screenshots you submit.
2. The information does not contain personal or sensitive data.
3. You understand that this project is an alpha prototype and not a production-ready operating system.

## Bug reports

Use the bug report template under `.github/ISSUE_TEMPLATE/bug_report.md`.

Include:

- version information
- boot method
- reproduction steps
- expected vs actual behavior
- screenshots or logs when available

## Feature requests

Use the feature request template under `.github/ISSUE_TEMPLATE/feature_request.md`.

Please keep suggestions focused on the project goal, compatibility, usability, or early user experience improvements.

## Commercial / licensing discussions

For commercial use, licensing, distribution, or resale inquiries, contact the project owner through the official channels listed in the README and the project website.

## Code and distribution policy

This project is not a public open-source community project.

Do not assume that unapproved pull requests, forks, or redistributed images are allowed. The project owner retains all rights to the repository contents and distribution assets unless a separate written agreement states otherwise.

## Safe testing

Use the project only on disposable devices or in a virtual machine. Always back up important data before writing a disk image to a physical drive.
