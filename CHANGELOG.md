# Changelog

All notable changes to the ThreeCreative OS Saviour project will be documented in this file.

## [0.2.0] - 2026-10-13

### Added
- Windows 1-inspired desktop concept environment
- Bootable x86_64 disk image packaging
- README and project overview
- Early-stage app and utility concept layout
- Command prompt access and desktop-style demonstration flow

### Changed
- Refined project presentation for clearer repository structure and release readiness
- Improved product framing for prospective buyers and testers
- Added stronger repository documentation to support trust and discovery

### Security / Distribution
- Added checksum guidance and release verification section
- Clarified rights and commercial distribution restrictions

### Notes
- This release is still an alpha-stage prototype and is not a production-ready operating system.
- Use only on disposable hardware or in a virtual machine for testing and evaluation.
